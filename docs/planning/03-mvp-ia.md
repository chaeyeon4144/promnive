# MVP 범위와 IA: 무엇을 먼저, 어디에 두는가

- 작성일: 2026-11-24
- 단계: P1 기획 — MVP (Minimum Viable Product, 가장 작게 쓸 수 있는 첫 버전) + IA (Information Architecture, 화면 구조)
- 이전 문서: [PRD](02-prd.md)

> PRD가 "무엇이 있어야 하는가"였다면,
> MVP는 "그중 **무엇을 먼저** 넣는가", IA는 "그걸 **어느 화면에** 두고 어떻게 오가는가"다.

## 1단계의 조건 (P0에서 정한 것)

- 시기: 2026-12 첫 버전
- **로그인 없음**
- 데이터는 운영자가 직접 넣는다 (mock JSON)

→ 로그인이나 서버가 꼭 있어야 하는 기능은 1단계에서 빠진다.

## MVP: 1단계에 넣을 것과 나중에 할 것

### 1단계에 넣는다

| 화면 | 기능 | 비고 |
|---|---|---|
| 상세 | 결과 예시 · 복사 · 빈칸 채우기 · 이용 방법 · AI로 바로가기 · 공유 · 출처 · 관련 프롬프트 | 서비스의 핵심. 릴스 링크로 온 사람이 바로 쓰는 곳 |
| 상세 | 저장 | **이 기기에만 저장** (아래 "보관함 결정" 참고) |
| 홈 | 주제 칩 · 카드 줄 · 사용법 한 줄 | 주제 칩을 누르면 홈 안에서 거른다 (아래 "필터 위치 결정" 참고) |
| 보관함 | 목록(주제별) · 바로 복사 · 지우기 | 이 기기에 저장한 것만 보인다 |

### 나중에 한다

| 기능 | 언제 | 이유 |
|---|---|---|
| 카카오 · 구글 로그인 | 2단계 (2027-01) | P0에서 1단계는 로그인 없이 가기로 했다 |
| 서버 보관함 | 로그인 도입 후 | 로그인이 있어야 "누구의 보관함인지" 알 수 있다 |
| 검색 | 프롬프트가 늘어난 뒤 | 1단계 프롬프트는 30개라 주제 칩으로 충분히 찾는다. 릴스로 온 사람은 링크로 상세에 바로 들어온다 |
| PRD "나중에 할 것" 전부 | 출시 후 | AI 캐릭터 대화, 보관함 메모, 내 정보 자동 채우기, 카카오 공유 카드, 이벤트 배너 |

## 결정: 1단계 보관함 (PRD TODO)

**이 기기에만 저장한다.** 브라우저 안의 저장 공간(localStorage)에 저장한 프롬프트를 기억한다.

| | 내용 |
|---|---|
| 이유 | P0 목적이 "바로 복사하고, **저장해서 다시 찾게**"다. 저장을 빼면 목적의 절반이 빠진다. 서버와 로그인 없이 할 수 있다 |
| 한계 | 다른 기기에서는 보이지 않는다. 브라우저 기록을 지우면 사라진다 |
| 대응 | 보관함 화면에 "이 기기에만 저장돼요" 안내를 둔다 |
| 포기한 것 | 1단계에서 저장을 아예 빼는 방법. 만들기는 쉽지만 다시 찾을 방법이 없어진다 |

## 결정: 필터 위치 (PRD TODO)

**홈 안에서 거른다.** 주제 칩을 누르면 홈의 카드 줄 대신 그 주제의 카드만 보인다. 별도 페이지는 만들지 않는다.

| | 내용 |
|---|---|
| 이유 | 프롬프트가 30개라 주제별 페이지를 따로 만들면 페이지마다 카드가 몇 개뿐이라 비어 보인다 |
| 포기한 것 | 주제마다 따로 있는 주소 (예: 주제 페이지 링크 공유). 프롬프트가 늘어나면 다시 검토한다 |

## IA: 화면 구조

### 화면 목록 (1단계: 3개)

| 화면 | 하는 일 |
|---|---|
| 홈 | 주제 칩으로 구경하고, 카드를 골라 상세로 간다 |
| 프롬프트 상세 | 결과를 보고, 빈칸을 채워 복사하고, AI로 가고, 공유하고, 저장한다 |
| 보관함 | 이 기기에 저장한 프롬프트를 주제별로 보고, 다시 복사하고, 지운다 |

로그인 화면은 1단계에 없다.

### 모든 화면 위에 있는 것 (헤더)

- 로고 → 홈
- 보관함 아이콘 → 보관함

### 화면 사이 이동

```
      [릴스 링크] ─────────────┐   (입구 1: 대부분 여기로 온다)
                               ▼
[홈] ──카드 누르기──────▶ [프롬프트 상세] ──AI로 바로가기──▶ (외부 AI 사이트)
 ▲   (입구 2)                 │  ▲
 │                            │  └──관련 프롬프트 누르기 (다른 상세로)
 │                            │
 └────── 헤더 로고 ───────────┤
                              │
[보관함] ◀──헤더 보관함 아이콘─┘
   │
   └── 빈칸 있는 프롬프트 "채우고 복사" ──▶ [프롬프트 상세]
```

- **입구가 2개**다. 홈으로 들어오는 사람보다 릴스 링크로 **상세에 바로** 들어오는 사람이 더 많을 것이다 (PRD 사용자 이야기 A).
- **저장은 이동이 아니다.** 상세에서 저장을 눌러도 화면은 그대로이고, "저장했어요" 같은 짧은 알림만 보인다.
- 빈칸 없는 프롬프트는 보관함에서 **이동 없이 바로 복사**한다.
