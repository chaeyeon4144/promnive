# P0: 서비스 정의

- 작성일: 2026-11-23
- 단계: P0 (기획의 첫 단계: 누구의 어떤 문제를 어떻게 푸는가)

## 한 줄 정의

> **인스타에서 재미용 AI 프롬프트를 보고 따라 해보고 싶은 사람**이, 프롬프트를 **댓글·DM으로 받아야 하고 받아도 흩어져서 다시 찾기 어렵다**
> → **Promnive는 연애·사주·취향 이미지 같은 재미 프롬프트를 AI 도구별·주제별로 모아 보고, 바로 복사하고, 내 보관함에 저장**하게 한다.

## 누구를 위한 서비스인가

**ChatGPT 정도는 써봤고, 인스타에서 재미 프롬프트를 보고 "나도 해볼래!" 하며 댓글을 다는 사람.**

| 후보 | 판단 | 이유 |
|---|---|---|
| AI를 거의 안 써본 사람 | 제외 | "프롬프트"라는 말을 모르면 이 사이트를 찾아올 길이 없다 (지인 인터뷰에서 확인) |
| AI를 잘 쓰는 사람 | 주 대상 아님 | 업무용 프롬프트를 찾거나 직접 짜서 쓴다. "재미용"이라는 차별점과 맞지 않는다 |
| **그 사이 (라이트 사용자)** | **주 대상** | AI에 붙여넣을 줄은 알고, 이미 "DM으로 받고 잃어버리는" 불편을 겪고 있다 |

→ 전문가가 아니므로 화면은 쉬운 말로, "복사 → AI에 붙여넣기"를 한 번에 할 수 있게 만든다.

## 문제

1. 프롬프트를 받으려면 **팔로우 + 댓글 → DM**을 거쳐야 한다.
2. 받은 프롬프트가 **DM, 스크린샷, 메모 앱에 흩어져서** 다시 쓰려면 앨범을 뒤져야 한다. **누구에게 받았는지**도 잊어버린다.
3. ChatGPT, Claude, Gemini, 이미지 생성 AI 등 **AI 도구마다 맞는 프롬프트**를 고르기 어렵다.
4. 업무용 프롬프트를 모은 곳은 많지만, **연애·사주·취향 이미지 같은 재미용 한국어 프롬프트**를 모은 곳은 드물다.

## 해결

- 재미 프롬프트를 **AI 도구별 · 주제별**로 필터링해서 본다.
- 버튼 하나로 **복사**한다.
- 마음에 드는 프롬프트를 **보관함**에 저장해서 다시 찾는다.
- 프롬프트마다 **출처(만든 크리에이터)**를 함께 보여준다.

## 차별점

| | 비슷한 서비스 (예: 프모아) | Promnive |
|---|---|---|
| 프롬프트는 누가 만드나 | 운영자가 직접 만들고 검증 | 운영자 검증 **+ 인스타 크리에이터**가 만든 것 |
| 받는 방법 | 사이트에서 검색 | 크리에이터가 DM 대신 **링크 하나**로 공유 |
| 다시 찾기 | 북마크 | 보관함 + **누구에게 받았는지(출처)**가 함께 남음 |
| 분위기 | 귀여운 캐릭터, 설명 위주 | **에디토리얼 아카이브** (트렌디하고 감각적인 매거진 느낌) |

**양쪽 모두에게 이득이다.**

- 사용자: DM을 뒤지지 않아도 된다.
- 크리에이터: 댓글마다 DM을 보내지 않아도 되고("프롬프트는 프로필 링크에"), 카드에 이름이 표시되어 홍보가 된다.

### 원칙: 허락 없이 가져오지 않는다

- 크리에이터의 프롬프트는 **허락을 받은 것만** 올리고, **출처를 표시**한다.
- 인스타 콘텐츠를 자동으로 긁어오지(스크래핑) 않는다. 인스타 이용약관이 금지한다.

## 비슷한 서비스 분석

| 서비스 | 정체 | 좋은 점 | 불편한 점 |
|---|---|---|---|
| **인스타그램** (지금 방식) | 릴스로 프롬프트를 소개하고 댓글·DM으로 공유 | 트렌디한 프롬프트가 빨리 올라온다. 영상으로 보여줘서 "나도 해볼래"가 쉽다 | 팔로우·댓글·DM을 거쳐야 하고, 저장이 안 돼서 다시 찾으려면 앨범을 뒤져야 한다 |
| **carat** (한국) | 프롬프트 공유보다 **AI로 이미지·영상을 만드는 서비스** | 채팅창에서 바로 만들 수 있다 | 필터링이 직관적이지 않다. 프롬프트를 얻기보다 결과물 공유에 초점이 있다 |
| **OpenPrompt** (한국, prpt.ai) | 프롬프트 공유 사이트 | 이미지형·텍스트형, 카테고리 필터가 빠르다. AI 활용 가이드와 소식도 있다 | 첫 화면에서 무슨 서비스인지 소개가 부족하다. 카드에 태그가 없어 이미지로만 종류를 짐작해야 한다 |
| **FlowGPT** (해외) | 프롬프트 공유보다 **테마를 학습한 AI와 바로 대화**하는 곳 | 카드를 누르면 그 주제로만 대화가 이어진다 | 카드가 어떤 테마인지 이미지로만 알아봐야 한다. 필터링이 친절하지 않다 |
| **프모아** (한국) | 운영자가 만들고 검증한 프롬프트 모음 | 기획 방향이 가장 비슷하다. "직접 검증" 태그, AI 숙련도, 소요 시간, 결과 예시, 옵션 설정(출력 비율 등)까지 잘 되어 있다 | 디자인이 AI로 만든 서비스처럼 느껴진다. 크리에이터 출처 개념은 없다 |

### 카드에서 발견한 정보 (데이터 모양 설계 재료)

제목, AI 이름(ChatGPT·Midjourney 등), 카테고리(커플·셀피·반려동물 등), 난이도(입문자 추천), 소요 시간, 대표 이미지(결과 예시), 좋아요 수, 조회수, 작성자, 북마크, 검증 태그, 옵션(출력 비율 등), 관련 프롬프트
